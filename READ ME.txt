# ?? DM HTML5 Game

Welcome to **DM HTML5 Game** — a fun browser-based gaming project built with **HTML5, CSS3, and JavaScript**.

The goal of this project is to create a simple place where users can open the website, choose a game, and start playing directly in their browser without needing to install a large application.

---

## ?? About DM HTML5 Game

**DM HTML5 Game** is designed to provide:

* ?? Browser-based HTML5 games
* ?? Fast and lightweight gameplay
* ?? Support for phones, tablets, and computers
* ?? User name support
* ?? 5-second game countdown
* ? Animated game loading
* ? Ability to load more games
* ?? Modern gaming interface
* ?? No complicated installation
* ?? Built using HTML, CSS, and JavaScript

The project can start with 50 games and continue expanding with more games over time.

# ?? Technologies

DM HTML5 Game uses web technologies including:

* **HTML5** — Website structure
* **CSS3** — Design and animations
* **JavaScript** — Game logic and interactions
* **Canvas API** — Browser game graphics
* **Local Storage** — Saving certain user information locally

The project is designed to run directly in modern web browsers.
